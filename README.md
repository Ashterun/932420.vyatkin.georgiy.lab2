Вторая лабораторная работа по предмету "Web-технологии": HTML-страница "О себе" (1 вариант: "Студент-разработчик")

Используемые технологии:
1. HTML5
2. CSS3
3. Visual Studio Code
4. GitHub

Структура HTML:
1. header – шапка с моим именем/фамилией и заголовком страницы
2. main – основной контент
3. Две секции section: «Навыки» (языки программирования, которыми я лучше всего владею) и «Проекты» (мои учебные проекты)
4. aside – боковая панель с краткой информацией (мои любимые технологии)
5. footer – подвал с копирайтом и годом
6. Одно изображение (аватар) с атрибутами src, alt, width, height
7. Форма обратной связи: поля «Имя», «Email», «Сообщение», и кнопка отправки
8. Цветовая гамма: сине-белая

Структура CSS:
1. Основной стиль – во внешнем файле; 1 элемент с inline стилями; 1 правило во внутреннем блоке style
2. CSS переменные в :root для цветов и шрифтов
3. Примеры позиционирования: static, relative, absolute
4. Состояния элементов: :hover, :active, :focus, :visited
5. Cписок навыков оформлен как сетка карточек-плиток

Как запустить:
1. Скачайте или клонируйте репозиторий
2. Откройте файл index.html в любом браузере
